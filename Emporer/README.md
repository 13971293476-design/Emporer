# Emperor · 在线卡牌对决

一个零依赖的双人网页联机游戏。服务端使用 Node.js 内置 HTTP 模块，玩家资料和牌局以 JSON 文件持久化，不需要安装 npm 包。

## 启动

```bash
node server.js
```

然后打开 <http://localhost:3000>。在两个浏览器窗口分别注册两个玩家，点击「寻找对手」即可匹配。

也可以点击「创建房间」，把 6 位房间码发给好友；好友在大厅输入房间码即可进入同一局。

牌局结束后，任一玩家点击「再来一局」即可发起重赛；另一位玩家点击同一个按钮后会自动进入新牌局，也可以使用显示的房间码加入。

## 规则实现

- 皇帝方有 1 张皇帝牌、4 张平民牌；奴隶方有 1 张奴隶牌、4 张平民牌。
- 奴隶方先出牌，双方每次出牌最多思考 60 秒。
- 超过 60 秒时，服务器会从当前剩余手牌随机出牌。
- 皇帝 > 平民、平民 > 奴隶、奴隶 > 皇帝。
- 两张牌都揭示后，只要有皇帝牌或奴隶牌出现，本局立即结束；双方都出平民则短暂展示本轮牌面后进入下一轮。
- 玩家密码使用 Node.js `scrypt` 加盐摘要后保存，原始密码不会写入数据库。
- 手牌只在服务端按玩家身份返回，对手未揭示的牌不会出现在接口响应中。
- 登录会话使用 HttpOnly、SameSite cookie；请求体、登录尝试、来源和静态资源路径均有限制。

## 数据

首次运行会自动生成 `data/db.json`。部署到云服务器时，为进程保留 `data/` 的写入权限即可。当前版本通过浏览器每秒轮询同步牌局，适合小规模房间；如果之后需要大量并发，可将房间状态迁移到 Redis，并把同步层换成 WebSocket。

可用环境变量：`PORT`（默认 `3000`）、`HOST`（默认 `0.0.0.0`）、`DATA_DIR`（数据库目录）。HTTPS 反向代理部署时设置 `COOKIE_SECURE=true`。

运行服务端测试：

```bash
node --test
```
